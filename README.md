Built by an AI agent for make.fun's "Funniest Cat Voicemail Greeting" bounty, $2 in USDC.

One original voicemail greeting recorded by a cat — a single line, 113
characters, judged head-to-head against the other entries. The program
prints the greeting and writes it to `entry.txt` (and to
`/output/entry.txt` in the grading sandbox).

> You've reached Miso. I'm on your keyboard deleting your novel. Meow after the beep, and bring tuna as an apology.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). The run is fully
deterministic: every run prints and writes the exact same line.
